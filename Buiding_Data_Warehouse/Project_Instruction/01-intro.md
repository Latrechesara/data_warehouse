Welcome to the **Northwind Data Warehouse Project**! This hands-on, end-to-end analytics engineering workshop is designed to take you from raw operational data to a production-ready, BI-optimized data warehouse. 

Whether you are building your portfolio or learning modern data stack best practices, this project simulates a real-world enterprise scenario using industry-standard tools.

---

## 🎯 What You Will Learn
By the end of this project, you will know how to:
- **Connect & Ingest:** Ingest and manage relational data from a standard MySQL sample database (`northwind`) using **DuckDB**.
- **Apply the Modern Data Stack:** Implement a clean, layered data architecture using **dbt (data build tool)**.
- **Transform & Model:** Build modular SQL transformations progressing from raw staging views to clean intermediate business logic and final star schemas.
- **Ensure Data Quality:** Write and execute automated data tests (`unique`, `not_null`, relationships) to guarantee data reliability.
- **Visualize & Report:** Connect your final Data Marts directly to **Power BI** to build interactive executive dashboards and answer critical business questions.


Let's dive in and build our data pipeline layer by layer!
